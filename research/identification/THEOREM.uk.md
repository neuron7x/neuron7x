# Межі ідентифікації в каталозі механізмів

Нехай для кожної пари різних зондів `p,q` множина `B(p,q)` містить усі індекси рядків, що мають унікальний підпис на цій парі. Випадок одного зонду входить у будь-яку пару з ним, бо додатковий результат не руйнує унікальність. Принаймні два зонди доступні.

- `U` рахує синглетони всього вектора.
- `W = |⋃ B(p,q)|` допускає окрему пару для кожної істини. Це аналог існування навчального прикладу, який може вибрати той, хто вже знає відповідь. [Goldman і Kearns, 1995](https://doi.org/10.1006/jcss.1995.1003)
- `K = max_p |⋃_{q≠p} B(p,q)|` вимагає одного наперед відомого кореня.
- Якщо `C(p,y)` є множиною рядків із результатом `y` на зонді `p`, то `A = max_p ∑_y max_{q≠p} |C(p,y) ∩ B(p,q)|`. Після кореня результат визначає один другий зонд для всієї гілки. Оптимальні продовження різних гілок незалежні. Одноелементна гілка може зупинитися відразу.
- `F = max_{p,q} |B(p,q)|` вимагає тієї самої пари для всіх істин.

Звідси `N ≥ U ≥ W ≥ K ≥ A ≥ F`. Кожне обмеження звужує множину допустимих свідчень чи планів. Для фіксованого кореня прямий оракул перевіряє підмножини бажаних істин. Для кожної першої відповіді перетинає множини других зондів, які ізолюють кожну з бажаних істин у гілці. Підмножина досяжна тоді й лише тоді, коли всі такі перетини непорожні. Це перевіряє максимум `A` без обчислення суми максимумів.

Кожна нерівність окремо може бути строгою. Для рівно однієї втрати приклади такі:

| Втрачена можливість | Бінарні рядки | N, U, W, K, A, F |
|---|---|---|
| Повний підпис не розділяє моделі | `00,00` | 2,0,0,0,0,0 |
| Два зонди не дають індивідуального свідчення | Усі 8 рядків від `000` до `111` | 8,8,0,0,0,0 |
| Індивідуальні свідчення несумісні за коренем | `0000,0001,0010,0111,1011,1111` | 6,6,6,3,3,3 |
| Спільна гілка вимагає несумісних продовжень | `1000,0100,0010,0001` | 4,4,4,4,2,2 |
| Фіксована пара втрачає від розгалуження | `000,010,100,101` | 4,4,4,4,4,2 |

Незалежний від істини випадковий вибір дерева дає суміш його покриттів. Він не збільшує максимум середнього покриття за рівномірної істини й двох зондів на траєкторію. Для мінімаксної ймовірності успіху результат інший: у чотирьох one-hot рядках кожне фіксоване дерево має принаймні одну істину з нульовим успіхом, а рівномірний вибір двох різних зондів дає кожній істині ймовірність `1/2`.

Коли два механізми мають однаковий повний підпис, вони дають однаковий запис за кожного можливого рішення планувальника. Індукція за кроками діє і для адаптивної політики з довільним детермінованим внутрішнім обчисленням. Власні передбачення планувальника можуть змінити вибір зонду. Вони не додають нової відповіді від механізму. Висновок залежить від повноти оголошеного каталогу й набору доступних втручань.

Для класу з `m` однакових підписів, якщо протокол вимагає назвати одну модель, мінімальна за моделями ймовірність правильного вибору не перевищує `1/m`. Розподіл виходу політики однаковий для кожної з `m` істин. Сума ймовірностей назвати ці `m` ідентичностей не перевищує одиниці. За заборони помилки висновок про одну фізичну модель в такому класі неможливий. Додавання до каталогу нового механізму з тим самим підписом спростовує безумовну унікальність попереднього висновку без зміни будь-якої відповіді.
