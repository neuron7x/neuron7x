# A04 · Збіг прогнозів і розширення репертуару спостережень

A03 встановив еквівалентність фізичних гіпотез у межах семи зондів. A04 перевіряє, скільки з цих невизначеностей зникає зі зміною множини доступних входів. Гіпотези, несправності й початкові сім зондів зафіксовані в A02. Новий контракт не змінює двокрокового критерію A01/A02. Тут визначається межа повного підпису на ширшій скінченній множині.

Для всіх 176 випадків ISCAS’85 читаємо піновані Verilog і запечатані входи A02. До кожного випадку додаємо 64 вхідні вектори з бітами за правилом A02 і префіксом `A04`. Порядок і повтори зберігаються. Для c17 використовуємо всі (2^5=32) вхідні вектори в лексичному порядку. Для нього рівність підписів перевіряється на всьому просторі входів. Для решти результат стосується лише протестованих входів. Префікси 4, 8, 16, 32 і для решти 64 дають описові точки кривої.

Первинна величина — частка рядків із неунікальним семизондовим підписом, які стали унікальними після всього розширення. Додатково звітуємо залишкові збіги по всіх випадках та окремо для c17. Правило 50% заморожує смисл слова «більшість» у цьому акті. За рівно 50% оцінка «половина». Ці підрахунки не оцінюють частоту збігів за межами зафіксованого каталогу.

Усі початкові відповіді мають побайтово збігтися зі скалярною симуляцією A02. Розширене виконання використовує окремий бітовий інтерпретатор примітивів Verilog. Для випадку 0 кожної схеми перевіряємо всі додані вектори окремим скалярним інтерпретатором A02. Якщо будь-яка нова колонка зменшує кількість унікальних рядків, змінилося джерело, є розбіжність інтерпретаторів або порушений розклад — прогін недійсний. Повтор проводиться в двох чистих Git-архівах.
