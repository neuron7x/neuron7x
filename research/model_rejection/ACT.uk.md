# Акт A06 · Перевірка каталогу з бюджетом два

**Рішення — спростовано практичну перевагу за наперед заданим критерієм.**

| Показник | Базова політика | Перевірка каталогу |
|---|---:|---:|
| Правильні ідентифікації в каталозі | 6928 / 7280 | 6928 / 7280 |
| Хибні однозначні висновки поза каталогом | 21488 / 21840 | 20784 / 21840 |
| Спростування каталогу поза ним | 0 | 704 |
| Зондів сумарно на задекларованих істинах | 14384 | 14560 |
| Зондів сумарно на незадекларованих істинах | 42448 | 43680 |

Скорочення хибних висновків **3,2234 в. п.** за порога **10 в. п.** У 176 із 1820 каталогів політика уникнула частини помилок. Додаткова вартість становила приблизно **0,0242** зонда на задекларовану істину. Позакаталожні частоти належать цьому вичерпному перебору з рівними вагами, без припущень про поширеність механізмів поза панеллю.

Однозначний листок глибини d після різних бінарних зондів фіксує d координат. У чотирибітній абетці до нього потрапляє 2^(4−d) векторів. Рівно один із них належить каталогу. Тому за двох зондів один правильний однозначний висновок коштує щонайменше три позакаталожні вектори з тим самим висновком. Правило перевірки досягло цієї межі в усіх каталогах. За незмінного протоколу покращити число хибних однозначних висновків далі можна лише ціною покриття. Додаткові різні зонди або інша політика видачі висновку змінюють саму задачу.
